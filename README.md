# 🎮 Tic-Tac-Toe Game

A simple Tic-Tac-Toe project created as part of my S&AI Git and GitHub practice.

## 📌 About the Project

Tic-Tac-Toe is a two-player game where players take turns marking spaces on a 3×3 grid. The first player to align three marks horizontally, vertically, or diagonally wins the game.

## 🛠️ Technologies Used

- **Java** — Game logic and winner detection
- **CSS** — Styling and visual design

## 📂 Project Structure

```text
snai-git-practice/
├── README.md
├── TicTacToe.java
└── style.css
```

## 🚀 How to Run

1. Make sure Java is installed.
2. Open Terminal in the project directory.
3. Compile the Java program:

   ```bash
   javac TicTacToe.java
   ```

4. Run the game:

   ```bash
   java TicTacToe
   ```
